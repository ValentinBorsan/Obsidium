# Descrierea publică Obsidium

- `obsidium-description.md`: pentru un editor care interpretează Markdown.
- `obsidium-description.html`: fragment HTML pentru modul HTML/source al unui editor care îl acceptă.

Descrierea este în engleză, ca textul din captura paginii. Conținutul este scurt,
grupat după experiența jucătorului și separat de changelog-ul tehnic.

Dacă pagina afișează literal `##` și `**`, acel conținut nu este interpretat ca
Markdown în contextul respectiv. Folosiți formatul acceptat de editor:

1. Într-un mod HTML/source, introduceți fragmentul HTML.
2. Într-un editor exclusiv vizual, introduceți textul și aplicați titlurile,
   listele și bold-ul cu instrumentele editorului. Nu lipiți cod HTML în modul vizual.
3. Dacă există un mod Markdown, folosiți fișierul Markdown.
4. Verificați previzualizarea înainte de publicare.

Fragmentul HTML folosește titluri, paragrafe și liste standard, fără CSS,
fonturi externe sau scripturi. Aspectul final depinde de stilurile platformei.
Nu am modificat descrierea publicată sau README-ul tehnic al proiectului.
