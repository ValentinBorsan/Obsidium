# Demetrian Botany

[Browse Botany items and recipes](wiki.html?page=Botany-Catalog) · [Read the practical botany manual](wiki.html?page=Botany-Manual)

Living ore trees produce renewable resources. Grafting combines a rootstock and a species-bearing scion to create compatible hybrids.

## Hybrid Sapling Grafting
- **Ares Iron Sapling** + `2× Hades Coal Scion` ➔ **Astrape Redstone Sapling**
- **Midas Gold Sapling** + `2× Hermes Copper Scion` ➔ **Poseidon Lapis Sapling**
- **Midas Gold Sapling** + `2× Artemis Silver Scion` ➔ **Electrum Sapling**
- **Ares Iron Sapling** + `2× Artemis Silver Scion` ➔ **Apollo Quartz Sapling**
- **Astrape Redstone Sapling** + `2× Apollo Quartz Scion` ➔ **Dionysian Amethyst Sapling**
- **Plouton Emerald Sapling** + `3× Tartarean Netherite Scion` ➔ **Adamantine Diamond Sapling**

## Automation
- **Demetrian Bonsai Planter** — Grows Living Ore Trees compactly in a single block and outputs nuggets, fruits, and saplings.
- **Demetrian Lumber Depot** — Centralizes automated tree harvesting.
- **Geothermal Arborist** (also available as a **Mythic Rails** cart module!) — Harvests trees along rail lines and replants saplings automatically.
