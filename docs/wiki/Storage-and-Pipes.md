## 1. Digital Storage Network
- **Storage Controller & UI:** Unified `[Items]`, `[Fluids]`, and `[⚔ Tools] Armory` views.
- **8-Bay Disk Drive:** Holds Item & Fluid Storage Disks (`32k – 256k` capacity).
- **Auto-Filters & Wireless:** Supports remote terminal access and automated crafter nodes.

## 2. Fluid Barrels & Tanks
- **Volcanic Wood Liquid Barrel:** `64,000 mB` (crafted with 4 logs + 4 plates + barrel)
- **Reinforced Volcanic Barrel:** `256,000 mB` (barrel + 4 bronze + 4 obsidian)
- **Dionysian Aging Barrel:** `1,024,000 mB` (Core + 7 Casings)
- **Supreme Liquid Tank (`2×2×2`):** `1,600,000 mB` (auto-forms when placed in a `2×2×2` cube)

## 3. Pipes & Energy Wires
- **Hermes Item Pipe:** High-speed point-to-point item logistics (right-click face to cycle `EXTRACT` / `INSERT`; auto-routes to Storage Controller).
- **Volcanite Optic Fiber:** Digital network cable linking external chests, barrels, and machines to the Storage Grid (Shift-right-click with Wrench to configure).
- **Naiad Fluid Pipe (`1,000 mB/t`):** Pressurized fluid pipe carrying Water, Lava, Steam & Pyroclastic Fuel. Equip **Naiad Valve Module** for strict one-way auto-pumping with zero cross-contamination.
- **Astrape Energy Wires (T1–T4):** Zero-loss instant BFS grid: `25k` / `250k` / `2.5M` / `25M RF/t`. **Right-click** an existing wire with a higher tier to upgrade in-place!
- **Poseidon Abyssal Pump:** Deep-ocean multiblock fluid extractor.

## 4. Universal Conduit — Magmatic Flux Conduit

[View the universal conduit image and crafting recipe](wiki.html?page=Transport-Catalog#item-obsidium-volcanite_universal_conduit)

The **Magmatic Flux Conduit** (`obsidium:volcanite_universal_conduit`) combines item, fluid and RF transport. Each face supports an **Item**, **Fluid**, **Energy** or **Omni** channel.

- Use a wrench on a face to cycle its transfer mode.
- Sneak while using the wrench to cycle the face channel type.
- Open the face configuration GUI to install compatible transfer upgrades.

This is separate from the **Volcanite Optic Fiber**, which serves the storage network.
